DATA QUALITY & VERIFICATION

Make the status of every field clear

Finding a data point and confirming its current validity are different tasks. I keep that distinction visible in the handoff.

VERIFIED

Marked as verified by source

When the source workbook or tool reports a verified status, I can preserve that label and name the source. It should not be interpreted as a permanent guarantee of inbox placement.

UNVERIFIED

Not independently verified

Used when the source file contains no verification status or no independent check has been completed for the preview.

MISSING

Not found / unavailable

Blank source fields stay blank or are labelled “Not found”. I do not invent phone numbers, email addresses, websites or profile URLs.

REVIEW

Needs manual review

If two fields appear inconsistent or a record needs a human check, I keep the original value and flag the issue instead of silently changing it.

!

Verification status can change over time. A “Verified” label shown in a source file is reported as supplied; it is not a fresh test performed by this portfolio website.

PORTFOLIO EXAMPLE

Source labels and independent checks are not the same thing.

In the sample projects, the Law and Real Estate workbooks contain a “Verified” status label. The Dental workbook has no verification-status column, so its preview is labelled “Not independently verified”.
